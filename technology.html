The technology behind the robot

A practical stack combining AI, computer vision, software and robotics hardware.

AI

Artificial Intelligence

Provides the decision-making layer for estimating expression categories.

ML

Machine Learning

Learns patterns from examples so expressions can be classified.

CV

Computer Vision

Processes camera images and identifies useful visual information.

OP

OpenCV

A popular computer-vision library that can handle image processing and camera input.

PY

Python

A beginner-friendly language commonly used for AI and computer vision prototypes.

TF

TensorFlow / ML Framework

A possible framework for training or running an emotion-classification model.

FD

Facial Landmarks

Points around facial features can help describe expression changes.

HW

Microcontroller / SBC

Arduino, Raspberry Pi or another controller can drive the physical robot.
