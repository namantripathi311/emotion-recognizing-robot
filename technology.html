The technology behind the robot.

A practical stack that combines computer vision, a classification model, Python software and a small amount of robotics hardware.

Software

Six pieces of the software stack

Each piece has one job. Keeping them separate is what makes the system possible to explain — and possible to fix when it goes wrong.

AI

Artificial intelligence

The overall approach: build a system that can make a useful judgement from messy, real-world input.

ML

Machine learning

Instead of hand-written rules, the model learns which patterns tend to occur together in labelled examples.

CV

Computer vision

Turns a grid of pixel values into meaningful structures — edges, shapes, a face, then facial features.

LIB

Vision library

A library such as OpenCV handles camera capture, colour conversion and feature detection reliably.

PY

Python

A readable language with strong AI tooling, which makes the project easy for a class to inspect and change.

NN

Neural network

A small convolutional network outputs one score per expression category, and the highest score wins.

How it learns

Taught by examples, not by rules

A convolutional network starts with random weights. It is shown thousands of labelled images, guesses the label, measures how wrong it was, and nudges the weights slightly in the direction that reduces the error.

Repeat that millions of times and the network becomes good at the task it was trained for. But it also inherits every bias in the data — which is why the ethics page of this project matters as much as the technology page.
