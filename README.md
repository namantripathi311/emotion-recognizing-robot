# Emotion-Recognizing Robot — Exhibition Website

A responsive multi-page HTML/CSS/JavaScript website for a school/college AI + robotics exhibition.

## Pages
- index.html — Home
- about.html — Project overview and emotions
- how-it-works.html — Four-stage process
- demo.html — Interactive simulated emotion demo
- technology.html — AI/software/hardware
- applications.html — Applications
- ethics.html — Responsible AI and privacy
- future.html — Future possibilities
- team.html — Team members

## Run it
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Replace the sample team names in `team.html`.

## Important
The demo is intentionally simulated. It does not claim to actually read a person's mind or reliably determine their true emotions.

To connect a real camera + AI model later, keep the frontend and add a backend/model layer. Do not put secret API keys directly in browser JavaScript.
