Why simulate it?

Because the honest version is less impressive

A real model outputs a spread of probabilities, and the top score is often only 40–60% — nowhere near as tidy as a demo panel. It can also be confidently wrong.

So this page shows the interface a real system would need: an explicit estimate, a visible confidence score, and a reply that leaves room for being mistaken. Presenting it any other way would teach the wrong lesson.

Why that matters
Uncertainty An estimate is not a diagnosis

Privacy note. This page never requests a camera. If the project is later connected to a real camera, consent and on-device processing come first — a face is personal data, and a classroom is not a laboratory.
