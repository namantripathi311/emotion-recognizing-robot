How does it work?

Four stages connect computer vision, pattern analysis and a possible robot response. Every stage can also go wrong — so this page covers the failure modes too.

Capture Detect Analyse Respond
Step 01

Capture

The camera records a frame that contains a face. In a classroom demo the frame is processed and then discarded — nothing is uploaded or kept.

Step 02

Detect

Computer vision locates the face, then finds the features that carry most of the visible signal: the eyes, the eyebrows and the mouth.

Step 03

Analyse

A classification model compares those measurements with patterns it learned from example images. The output is a set of scores — not a fact.

Step 04

Respond

The robot chooses a deliberately gentle response — a phrase, a light, a movement — and, importantly, allows for the possibility that it is wrong.

Where it breaks

Four honest failure modes

A project that hides its weak points is not really teaching anything. These are the ones that matter most.

Lighting

Harsh shadows or a backlit face change the shape the camera sees, so the estimate shifts with the room — not with the person.

Partial faces

Glasses, masks, hair or a turned head hide the features the model relies on, which lowers confidence and raises error.

Cultural difference

Expressions are not universal in the way early datasets assumed. Training sets that under-represent people cause real, measurable unfairness.

Acting

People can produce a convincing expression without feeling it. A model that only sees the outside cannot tell the difference.

Design rule for this project: because stage 03 is only ever an estimate, stage 04 must never make a decision with real consequences. The robot suggests. It does not judge.
