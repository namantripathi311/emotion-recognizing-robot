How it was made

Three rules we worked to

Research before claiming

Every statement about accuracy, bias or privacy on this site had to be something we could explain out loud to a judge.

Design for real visitors

The site works on a phone in a crowded hall, with readable text, keyboard navigation and a dark mode for a dark room.

Say what it cannot do

The limitations are on the front page on purpose. A project that only shows its strengths is not teaching anything honest.

Project facts

What this website actually is

A static multi-page site, built with plain HTML, CSS and JavaScript — no framework, no tracking, no analytics, and no camera access anywhere on the site. It opens straight from a folder or any static host.
